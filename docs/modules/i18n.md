# rain-i18n

`rain-i18n` is the optional, Spring-free internationalization kernel. It owns typed deferred
messages, immutable content-addressed catalog snapshots, explicit locale/zone views, strict
`rain-mf2/v1` templates, structural rich parts and deterministic ICU4J-backed formatting. It does
not choose a process locale, mutate JVM defaults, open a database connection, or depend on servlet,
jobs, tenancy, or Spring.

The module is the explicit low-level SDK. `rain-i18n-web` is an optional magic-first integration;
persistence, jobs, tenancy and authoring integrations remain separate optional modules.

## Core contracts

- `CatalogCompiler` accepts an all-or-nothing `CatalogSpec` and produces an immutable
  `CatalogSnapshot`; its digest includes message contracts, review identities, locale policy and
  effective limits.
- `snapshot.resolve(...)` and `snapshot.view(ViewSpec(...))` make negotiation, zone and
  presentation explicit. A resolution or overlay from another snapshot is rejected.
- `MessageDefinition` and `MessageArguments` bind only closed `MessageValue` types. The manual
  DSL is the low-level escape hatch; neither raw maps nor `toString()` reach a template.
- `CatalogOverlayCompiler` validates complete reviewed application/tenant translations against their
  exact base snapshot. Overlay layer and digest become rendered-message provenance and cache identity.
- `CatalogController` provides process-local opaque-head activation, rollback, bounded retention and
  exact finite pins; durable release storage is deliberately not hidden in the kernel.
- `CatalogRuntimeIdentity` is an optional operator gate over grammar, engine and ICU/CLDR/tzdb
  identity. A mismatched artifact is refused before loading and a controller refuses it before
  activation/retention.
- `I18nObserver` receives only immutable low-cardinality resolution/render outcome data. It has no
  request/tenant/message-value context, and a failing observer is isolated from the catalog result.

## Closed outcomes and telemetry

| Boundary | Closed outcome | Required caller behavior |
|---|---|---|
| Source compiler | `CatalogCompilation.Refused` | Do not publish a partial snapshot. Report bounded structural problems to the author. |
| Artifact/trust loader | `CatalogArtifactDecoding.Refused` or `TrustedCatalogLoad.Refused` | Refuse storage and activation. A matching digest alone is never provenance. |
| Locale resolver | `LocaleResolution.Refused` | Follow the route's declared `406`/default contract; do not consult JVM defaults. |
| Renderer | `MessageRenderException` | Preserve machine/protocol fields and use the transport's safe fallback. Never retry under a newer catalog. |
| Controller | `CatalogTransition.Conflict`, `Missing` or `Limit` | Re-read the opaque head, retain the existing active snapshot and make the failed operation observable. |

`I18nObserver` has exactly these finite metric dimensions: `operation` is
`LOCALE_RESOLUTION|RENDER`; `outcome` is `RESOLVED|RENDERED|REFUSED|FAILED`; `localeReason` is the
closed `LocaleResolutionReason` enum or absent; `layer` is the closed `RenderLayer` enum or absent.
Message keys, rendered text, typed values, locale spelling, snapshot digests, tenant/principal IDs
and headers are forbidden labels. A Micrometer/trace adapter is optional and must map only these
dimensions.

## Dependency

```kotlin
dependencies {
    implementation(platform("com.gd.rain:rain-dependencies:0.1.0-SNAPSHOT"))
    implementation("com.gd.rain:rain-i18n")
}
```

## Status

The bounded context is release-ready. The checked-in i18n plan records the completed kernel,
toolchain, web, durable-release, jobs, tenancy and observability adapters; use the
[operations runbook](../concepts/i18n-operations.md) for release and capacity evidence.

The stable parser boundary is also documented by the executable
[rain-mf2/v1 conformance corpus](../concepts/rain-mf2-v1-corpus.md); a new grammar profile cannot
reinterpret these accepted or refused cases.
